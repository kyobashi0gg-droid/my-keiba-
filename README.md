# MY KEIBA LAB

スマホで使うことを前提にした、自分専用の競馬予想・分析メモの第1版です。

## 第1版の機能

- レース登録（開催場、R、レース名、天気、馬場、展開メモ）
- 出走馬ごとの人気、オッズ、調教印、前走比、33ラップ、脚質、メモ
- KTMの自動判定
  - 調教印が ◎ / ○ / ▲
  - 調教採点の前走比が +6〜+19
- 穴注目スコアの簡易自動抽出
- KTM / 穴注目だけに絞り込み
- 端末内に自動保存（localStorage）
- JSONでバックアップ / 復元
- PWA対応の基本構成（ホーム画面追加、オフラインキャッシュ）

## 注意

「穴注目」は第1版の簡易スクリーニングです。実際の最終予想では、33ラップの詳細、調教採点、展開、馬場、人気・オッズ、過去走内容などを組み合わせて精査する前提です。
